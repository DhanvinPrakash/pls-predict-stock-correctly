This is a simple app for Mac os using Apple's CoreML and Apple Intelligence to predict and tell the user to invest divest or hold their stock
using data from yahoo finance, we are storing it in a csv with a custom new table as the target for coreml while the rest of the data is used for training

Prerequisites
What things you need to install the software and how to install them:
Xcode 16 (Required for SwiftUI Layouts and Swift Charts framework)
macOS 26 and macbook with m1 or newer processor (required for coreml and apple intelligence)
Python 3.x (Required only for downloading and formatting the dataset)
yfinance & pandas libraries (For data collection pipeline)
